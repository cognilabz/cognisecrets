## Changes Since v0.2.3

## Migration

No manifest schema migration is required from `v0.2.3`.

Operators should expect fail-closed behavior when the Kubernetes API rejects a generated target Secret: an existing managed target Secret is deleted when ownership can be proven.

## Known Limitations

- `WriteFailed` conformance remains reference-implementation unit-test coverage only because operational Kubernetes write and delete failures are not portable to force in a black-box E2E suite.
- Published-image smoke testing should be performed after tag publication.
